GIF Generator

Unduh dan buat animasi GIF, MP4, serta paket gambar prakiraan maritim BMKG (CAWO, INAWAVES, dan PRAKSAR) secara lokal di komputer Anda.

Unduh GIF-Generator.exe Aplikasi Windows standalone, sekitar 11,5 MB. Tidak perlu memasang Python.

Cara menggunakan

  1. Unduh file GIF-Generator.exe dari Google Drive lewat tombol di atas, lalu klik dua kali.
  2. Jika Windows menampilkan peringatan "Windows protected your PC", klik More info lalu Run anyway. Peringatan ini muncul karena aplikasi internal belum ditandatangani.
  3. Browser terbuka otomatis. Jika tidak, klik tombol di bawah.
  4. Aplikasi menutup sendiri setelah tab browser ditutup dan tidak ada unduhan yang berjalan.

Buka GIF Generator

Mengapa harus diunduh?

Server maritim.bmkg.go.id memblokir akses dari Google Apps Script dan tidak mengizinkan CORS langsung dari halaman web. Aplikasi ini menjalankan server kecil di komputer Anda (127.0.0.1:8000) untuk mengunduh gambar langsung dari BMKG, sedangkan tampilannya tetap berupa halaman web.

Tidak terbuka? Muncul "tidak dapat dihubungi" berarti aplikasinya belum berjalan. Jalankan dulu file GIF-Generator.exe, lalu klik tombol lagi.
  • Komputer harus terhubung ke internet dan bisa mengakses maritim.bmkg.go.id.
  • Jika port 8000 sedang dipakai aplikasi lain, aplikasi otomatis membuka browser di port lain yang kosong.
