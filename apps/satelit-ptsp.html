Satelit PTSP

Unduh dan pratinjau citra satelit Himawari (HCAI dan RP) dari server FTP untuk keperluan PTSP.

Unduh CitraSatelitPTSP.exe Aplikasi Windows, sekitar 10 MB. Tidak perlu memasang Python.

Cara menggunakan

  1. Unduh file CitraSatelitPTSP.exe lalu klik dua kali.
  2. Jika Windows menampilkan peringatan "Windows protected your PC", klik More info lalu Run anyway. Peringatan ini muncul karena aplikasi internal belum ditandatangani.
  3. Browser terbuka otomatis. Jika tidak, klik tombol di bawah.
  4. Aplikasi menutup sendiri setelah tab-nya ditutup dan tidak ada unduhan yang berjalan.

Buka Satelit PTSP

Mengapa harus diunduh?

Browser tidak mendukung FTP, sehingga halaman web biasa tidak bisa mengunduh dari server citra satelit. Aplikasi ini menjalankan server kecil di komputer Anda (127.0.0.1:8765) yang mengambil file lewat FTP, sedangkan tampilannya tetap berupa halaman web.

Tidak terbuka? Muncul "tidak dapat dihubungi" berarti aplikasinya belum berjalan. Jalankan dulu file .exe-nya, lalu klik tombol lagi.
  • Komputer harus bisa mengakses server FTP citra (biasanya jaringan kantor).
  • Port 8765 tidak boleh dipakai aplikasi lain.
